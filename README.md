## Descripción del sistema

El proyecto consiste en el desarrollo de un Sistema de Gestión de Alquiler de
Bicicletas, que organiza el proceso completo de alquiler y devolución de bicicletas
pertenecientes a distintas sucursales.

El sistema permitirá registrar clientes y empleados, administrar sucursales, controlar el estado y disponibilidad de las bicicletas, gestionar categorías y tarifas, registrar alquileres con una o más bicicletas, y procesar los pagos correspondientes.

El objetivo es ofrecer una herramienta que facilite la organización de la información,
mejore el control de los alquileres y permita conocer el estado de cada bicicleta en
cualquier momento.

## Cómo ejecutar el sistema

1. Abrir la solución `*.sln` en Visual Studio.
2. Establecer el proyecto `WebApi` como proyecto de inicio.
3. Ejecutar la aplicación utilizando `Ctrl + F5` o `F5`.
4. Una vez iniciada la aplicación, acceder a Swagger desde la URL indicada por la aplicación para probar los endpoints disponibles.

### Prueba de la API

Desde Swagger se pueden consultar y probar los distintos endpoints disponibles para las entidades del sistema, incluyendo operaciones de alta, consulta, modificación y eliminación.
